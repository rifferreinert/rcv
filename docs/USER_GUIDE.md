# RCV Web App User Guide

## Sign In

Choose **Sign in with Google** or **Sign in with Microsoft**. The application does not manage passwords.

## Create a Poll

1. Open the dashboard and select **Create poll**.
2. Enter a title and optional description.
3. Add between 2 and 50 unique options.
4. Optionally choose a closing date and time.
5. Choose whether aggregate results are visible while voting remains open.
6. Create the poll and share its direct link.

Polls are unlisted: they do not appear in a public directory. Only people with the direct link can find the poll, while creators can see all their polls on the dashboard.

Creators may edit a poll before the first vote, close it early, or delete it. A scheduled deadline closes the poll when it is next accessed after that time.

## Vote

1. Open the poll's direct link and sign in if prompted.
2. Rank as many options as desired.
3. Drag options, use the keyboard controls, or use the move buttons to change their order.
4. Submit the ranking.

Partial ballots are valid. Each person has one ballot per poll and may revise it until the poll closes.

## Understand Results

Results contain aggregate counts only; individual ballots and voter identities remain private.

- If live results are enabled, anyone with the link can view the current snapshot.
- If live results are disabled, only the creator can view results while voting remains open.
- Final results are visible to anyone with the link after closure.
- A no-vote poll displays zero participation rather than a winner.
- A tie lists the tied options.

Each round shows current vote totals and the option eliminated before the next round. When a ballot's remaining choices have all been eliminated, it becomes exhausted and no longer contributes to later-round totals.
