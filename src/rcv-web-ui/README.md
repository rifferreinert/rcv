# RCV Web UI

React and TypeScript frontend for the ranked choice voting platform.

## Current Status

As of 2026-08-07, this project is a buildable Vite starter. Product routing, authentication state, API clients, poll pages, voting controls, and results visualizations have not been implemented.

The required frontend libraries are installed, including React Router, React Query, Axios, Tailwind CSS, dnd-kit, and Recharts.

## Development

```bash
npm ci
npm run dev
```

The development server runs at `http://localhost:5173`.

## Available Commands

```bash
npm run build
npm run lint
npm run preview
```
